# Graph Network Optimization: MST & Shortest Path

A Python showcase of Prim's and Dijkstra's algorithms for network routing and optimization.

## 📌 Problem Focus

This project explores two fundamental optimization challenges on weighted, undirected network topologies:
1. **Minimum Spanning Tree (MST):** Solved via **Prim's Algorithm**  to identify minimal infrastructure connectivity costs without cycles.
2. **Single-Source Shortest Path (SSSP):** Solved via **Dijkstra's Algorithm** for minimal-latency routing between specific endpoints.

## 📊 Features & Engineering

- **Adjacency Matrix Representation:** Custom matrix builder handling multi-edges by minimal weight filtering.
- **Traceback & Path Reconstruction:** Exact predecessor backtracking for path extraction.
